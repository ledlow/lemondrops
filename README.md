# lemon drops

Splash page for getlemondrops.com, migrated from write.as. Plain HTML with no build step.

- `index.html`: the page (styles are inline)
- `assets/bg.jpg`: background photo. **Add this file**: it's the image from https://i.snap.as/6118Xe6D.jpg
- `CNAME`: custom domain for GitHub Pages
- `.nojekyll`: tells GitHub Pages to serve files as-is
- `404.html`: sends any other URL back to the home page
- `favicon.ico`, `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`: lemon icons for browser tabs and the iPhone home screen
